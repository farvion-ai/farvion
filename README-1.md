# Farvion AI

**Satu asisten, bahasa apapun yang Anda pakai.**
*One assistant, whatever language you speak.*

Farvion adalah asisten AI multibahasa gratis untuk mengobrol, menulis, dan membuat kode. Mendukung Indonesia, English, Español, dan Melayu.

Farvion is a free multilingual AI assistant for chatting, writing, and coding, with voice call, real-time weather, and interactive artifacts.

🌐 **Coba sekarang / Try it:** [farvion.my.id](https://farvion.my.id)

## Fitur / Features
- 🗣️ Multibahasa asli (ID, EN, ES, MS)
- 📞 Voice call langsung
- 🧩 Artifact interaktif
- 🌦️ Cuaca real-time
